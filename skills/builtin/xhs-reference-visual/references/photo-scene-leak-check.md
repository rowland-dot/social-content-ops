# 泄漏检查（issue 103）

每一张画好的卡都做（小样、A/B/C/D 封面、成套的每一张）。用眼睛看，不读、不列、不报包装上印的字。画面里出现下面任何一条，这张卡不合格，并把泄漏的是什么写进这张卡的检查记录。

## 不合格的迹象

一级（图）：
- 【一级】学过的帖子或团队参考图里的品牌名、Logo、商品或包装出现在卡上（不是这个品牌自己 `products` 文件夹里的真实商品的，都算）；
- 【一级】学过的帖子或参考图里的人物、脸或角色出现在卡上；
- 【一级】徽章、贴纸、口味标或照搬整个版面（借构图仍然允许）；对比页上的图形或标记也算。

三级（字）：
- 【三级】学过的帖子或参考图里的功效、评分、前后对比或别的说法；
- 【三级】A/B/C/D 对比页上的标签、方向说明或别的字；
- 【三级】上一张卡或作为风格参考传入的封面上的字，不在这张卡自己确认过的字清单里。

## 和什么并排看

把画好的卡和提示词文件里记录的每一张传入的图并排看，唯独不含真实商品照、`--identity-image` 的模特图和作为 `--base-image` 传入的已批准的卡；再和同一套里上一张画好的卡并排看。提示词文件的格式不变。

## 不算泄漏

- `--identity-image` 传入的这个品牌自己的模特（issue 92）；
- 已批准的卡按 issue 91 修改时，它自己的画和字；
- 这张卡自己确认过的字；
- 参考图的样子：光线、场景、构图、字体风格；
- 只替换产品的卡，按计划里记下的替换模式，保留下来的参考图场景和道具（替换模式）。

## 对比页从不是输入

A/B/C/D 对比页，或任何拼在一起的图，从不传给 Codex。后面的卡要借选定的封面时，传选定封面自己的文件：打字字体的整套传设字之前的底图，和现在一样。

## 不合格怎么办

没有批准的卡照干净重出办；已批准的卡照“已批准卡的修改”办，仍从那张已批准的卡改起；或如实报告给用户。不能当合格交付。这一条不加新的重出办法，重出没有次数上限。

这是眼睛检查，不是机器检查。检查顺序里的位置见 [photo-scene-check-order.md](photo-scene-check-order.md)：图的泄漏在一级，字的泄漏在三级。
