# 封面方向先筛再留三个，混合选择（issue 99）

issue 88 的三个封面 A/B/C 之前，先在文字里筛候选方向；用户选“A 加 C”这样的混合时，建一个新的方向，不把两张封面叠在一起。细则都在这里；SKILL.md 只留步骤，指回这里。

负责人的规则（CLAUDE.md“Photo-scene post images follow one approval process”第 4 步）：。Lovart 复盘的缺口表 T2、T3 是出处，它的文件没有拿进来。

## 三个轴

- 轴就是负责人这句话里的三样：角度、取景、照片领头的东西。技能把它们定死，套系计划自己不挑别的轴。
- 套系计划在封面方向表上面写一行：`三个轴：角度、取景、领头`。`plan_page.py` 的 `build` 和 `covers` 读这一行，原样放上页；缺这一行，命令停下（退出码 2）。

## 先写候选，不画

- 封面方向表之前，套系计划里先写候选方向表，标题含“候选方向”，列：候选 / 借的图集 / 角度 / 取景 / 领头 / 留下或丢掉 / 理由。
- 至少五个候选。每个候选写明它借的图集（取自这篇帖子自己的主题研究，团队的参考图不算），和它的角度、取景、领头。一个图集可以有不止一个候选。
- 候选一个也不画：画五到八张封面会耗负责人的 ChatGPT 额度，筛选只在文字里做。

## 浅的丢掉

- 一个候选和另一个候选只差在颜色、背景色、姿势、小幅裁切或风格标签，就丢掉：浅的方向不是不同的方向。
- 每个丢掉的候选在“留下或丢掉”和“理由”两格写一行：它和哪个候选太像，像在哪里。
- 丢掉的候选只留在套系计划文件里，不上计划页。

## 留下三个

- 留下的三个借三个不同的图集，两两比较，角度、取景和领头三样都不同；只有一样不同、另两样一样，不算。
- 每个留下的方向在方向表的“和另外两个怎么不同”一格写一句，分别说它在角度、取景、领头上和另外两个怎么不同。计划页把这一句逐字放在方向旁边。
- “研究的图集”不足三套，或候选筛完凑不出三个合格的：告诉用户，然后停下。不放宽规则，不重用一个图集，也不凭空编方向。
- `plan_page.py` 的 `build` 对方向 A、B、C 两两检查角度、取景、领头；任何一对在某一轴上相同，或“和另外两个怎么不同”是空的，命令停下并写出行和轴。

## 混合选择

- 用户一起选了两个或更多方向（“A 加 C”），套系计划的方向表再加一行新的方向：方向一格写字母组合 `A+C`；借的图集写它用的一个或几个图集，用“、”分开；角度、取景、领头各写一个值；“和另外两个怎么不同”一格写每个值取自哪一个方向，例如“角度取自 A，取景和领头取自 C”；另有它自己的版面计划和“撞上的卡和改法”，记忆点一行，形式和 A、B、C 的一样。选定和这一行记下日期。
- 这个新方向只画一次，是一张新封面：按这一行和平时的输入（商品照、借的图集的参考、有人物时的人物参考）画，各项检查照旧。图存成 `cover-A+C.png`（或 jpg、jpeg、webp）放在 `images/`。
- 被选的几张封面的图不拼合、不叠加、不剪接，也不当作要改的图传进去；新封面从这一行写下的东西画。
- 命令 `plan_page.py covers --plan <set-plan.md> --mix A+C` 建只有这张混合封面的页，下面是它在方向表里的那一行，逐字复制；不带 `--mix` 的页照旧只有 A、B、C。
- 用户接受了才成为这套的封面；接受之后，[photo-scene-cover-versions.md](photo-scene-cover-versions.md)“用户选定之后”的各条照这张封面办，再选字体和样式。用户不接受，按他说的改这一行，再画一次新的，不改旧图。
