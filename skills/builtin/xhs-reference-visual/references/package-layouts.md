# 团队资料包和默认资料包里文件的位置

SKILL.md 和各个细则里写的文件位置，都是团队资料包里的位置，相对“资料包目录”。用默认资料包时（`references/defaults/`，不含参考图），下面这几份在别的位置；默认资料包里没有覆盖说明点名的那些句子，那些覆盖说明对它没有要处理的。

| 团队资料包里的位置 | 默认资料包里的位置 |
|---|---|
| `standards/ecommerce-natural-v1/STANDARD.md` | `standards/STANDARD.md` |
| `standards/ecommerce-natural-v1/CASES.md` | `standards/REFERENCE-BREAKDOWN.md`（拆解方法，不含图） |
| `standards/ecommerce-natural-v1/PORTRAIT-WORKFLOW-REVIEW-2026-10-20.md` | `methods/PORTRAIT-WORKFLOW.md` |
