# 帖子自己的主题研究：怎么存图集、怎么写小结（issue 84）

来源：负责人的规则（CLAUDE.md“Photo-scene post images follow one approval process”第 1 步）： 门在 SKILL.md“这篇帖子自己的主题研究”，这里只写这一步怎么做。

## 跑法

```bash
python3 skills/builtin/skill-xhs-note-reader/scripts/study_topic.py --brand <品牌文件夹名> --keyword "<这篇帖子的主题>" [-n 5]
```

- 一次搜索，按点赞加收藏的合计排名（排名公式只在 `skill-post-scorer`，这里不另抄一份），取最高的 N 篇图文，默认 5；每篇经守卫读一次，每张图经守卫的文件下载一步存下，整套（不只封面）。
- 不要用别的办法下载图，也不要绕过守卫。守卫拒绝（熔断、每天额度用完、没登录、账号正被占用）时，命令立刻停下并在索引里写明停在哪、为什么：照实告诉负责人，不要重试、不要循环等待。
- 存放：每一套一个文件夹，在 `outputs/<品牌>/品牌资料/对标笔记库/image-sets/` 下，名字 `<日期>-<主题>-<第几篇>-<标题>`，里面是 `01.jpg…`（按帖子里的顺序）、`contact-sheet.jpg`（一排总览）和 `record.md`（标题、作者、赞、藏、合计、图数、不带访问码的笔记地址）。这次研究自己的文件夹在 `.../对标笔记库/research/<日期>-<主题>/`：`index.md`（命令写）、`summary.md`（你写）、`raw/`（平台原样的回答，只有这里可以有访问码）。
- 视频帖不算一套：跳过，索引里写明。
- 同一天同一主题再跑一遍同样的命令，就是接着做或检查：不再搜索，已存好的帖子不再读，所有已存的图再检查一遍。

## 小结（你写，命令不写）

存完以后，对着每一套存下的真实图（`01.jpg…` 和 `contact-sheet.jpg`）写 `research/<日期>-<主题>/summary.md`：

1. 每一套一行：它的图是怎么做的（构图、字怎么放、用什么颜色、包装什么时候出现、第几张讲什么）。
2. 再写几套的共同点。
3. 每一套都要点名：写它在 `index.md` 里的文件夹名（一字不改）。没点名的套，命令算这次研究没做完。

写完再跑一遍同样的命令。退出码 0 才是做完；1 是有图缺了、打不开或不全，或某篇读不了（索引写明是哪一套哪一张）；3 是被守卫拦停；4 是图存好了但小结没写完。小结只写你从图上看到的，不凭空编。
