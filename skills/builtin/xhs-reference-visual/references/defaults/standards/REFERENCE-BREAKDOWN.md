# 怎样拆解一张参考图

拆解的对象是这篇帖子主题下排名靠前的真实帖子里的图。每张拆成三部分，写成一小段，不推定图像一定来自实拍，也不把图中商品的宣称当作事实。风格名称是归纳；字体只判断可见的类别，不猜字体名称。

## 每张图写三部分

1. **构图。** 主体在哪里、视线和手臂把眼睛引向哪里、前中后景怎么分、留白在哪里、裁切裁掉了什么。
2. **色光材质（含字体）。** 主色和辅色的关系，光从哪个方向来、软还是硬，质地靠什么表现（织物纤维、玻璃透光、液体、木纹、皮肤）。图上有文字时写字体类别、文字容器和层级；文字属于包装的，写明属于包装，不迁移。
3. **为什么有效，以及能借什么。** 这张图靠什么让人停下来或收藏；哪些手法可以借（光、构图、层级、节奏），哪些不借（文案、数字、品牌字、水印、条码、二维码、人物身份、功效说法）。

## 写法

- 一张图一段，先写它属于哪个风格分支（见风格记忆），再写三部分。
- 图太小或太糊时，只可靠地用于整体色调、构图和气氛，不把标签和精细纹理当标准，并写明。
- 图中有明显的瑕疵（错字、变形的标签）时写明，不继承。
- 一整套图集，最后加一段“套系学习重点”：哪几张在同一场景下变化机位与动作；哪几张的环境、配色和版式保持一致；哪几张各自承担不同的信息任务。

## 用法

拆完后选一张主参考、必要时一张辅参考，并写明各自的职责（主参考定义字体和布局，辅参考定义光线或场景）。不把全部参考混在一起。
