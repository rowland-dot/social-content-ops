# 小红书参考视觉：默认资料包

这是技能自带的默认资料包，不属于任何品牌或团队，不含参考图。用户有自己的资料包时，用用户自己的；没有时，由用户在默认资料包和自建资料包之间选。

| 文件 | 作用 |
|---|---|
| [skill/SKILL.md](skill/SKILL.md) | 入口：什么时候用，先读什么 |
| [file/DESIGN-MEMORY.md](file/DESIGN-MEMORY.md) | 风格记忆：三类字体、文字容器、按题材配色、六个风格分支、事实边界 |
| [playbook/PLAYBOOK.md](playbook/PLAYBOOK.md) | 流程手册：锁定需求、选方向、封面、检查 |
| [playbook/EXECUTION-BRIEF.md](playbook/EXECUTION-BRIEF.md) | 单张图的执行说明模板 |
| [standards/STANDARD.md](standards/STANDARD.md) | 十二条摄影标准、项目开始前的步骤、验收清单、去 AI 感标准 |
| [standards/REFERENCE-BREAKDOWN.md](standards/REFERENCE-BREAKDOWN.md) | 怎样拆解一张参考图（构图、色光材质、为什么有效） |
| [methods/PRODUCT-REPLACEMENT.md](methods/PRODUCT-REPLACEMENT.md) | 把商品放进参考场景：九步和经验 |
| [methods/PORTRAIT-WORKFLOW.md](methods/PORTRAIT-WORKFLOW.md) | 人像与修图：八步和经验 |
| [methods/PORTRAIT-PROMPT-RULES.md](methods/PORTRAIT-PROMPT-RULES.md) | 十四个摄影模块，可选，一次只用适用的几个 |

使用顺序：skill、设计记忆、流程手册、设计标准；做商品置换或人像时再读 methods 里对应的一份。整包搬移以保留相对引用。

状态：这是通用默认。风格归纳不自动升级为全局偏好；参考里的事实声明一律不核验，也不收进卖点库。
