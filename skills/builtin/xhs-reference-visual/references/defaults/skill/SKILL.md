# 小红书参考视觉复用（默认版）

这是默认资料包的入口。使用时以同包相对链接为准；搬移时保留整个资料包文件夹，不能只复制这一个文件。

仅在用户明确调用时使用。先读[风格记忆](../file/DESIGN-MEMORY.md)和该品牌自己的品牌文件（在品牌资料里，不在本文件夹），再完整阅读[流程手册](../playbook/PLAYBOOK.md)和[设计标准](../standards/STANDARD.md)。

选参考时，按[参考拆解](../standards/REFERENCE-BREAKDOWN.md)的方法拆这篇帖子主题下的真实高赞帖子，选一张主参考、必要时一张辅参考，实际打开原图看。按[执行说明模板](../playbook/EXECUTION-BRIEF.md)组织每张图片。

沿用已确认的选择，只询问缺失的关键条件。参考只负责视觉，不替代商品资料，不自动迁移功效文案或测评经历。出三个封面方向供用户挑选，选定后再展开；背景差异必须检查实际图片，不能仅依靠提示词。尺寸以导出文件核验，插值处理如实说明。
