# 小红书图文视觉：默认风格记忆

这是默认资料包，不属于任何品牌或团队。用户有自己的风格资料时，用用户自己的。

## 视觉共性

大部分小红书商品图文用真实感场景或商品照片作底层，再用有手作感的图文组织阅读路径；也有纯图形拼贴，不必每张都用实景。共同点是：明显的主标题、产品识别点、与内容有关的注释元素。

字体至少有三类，不一律归成同一种手写体：圆润的粗笔或细笔手写；有干刷和飞白感的白色笔字；厚重的无衬线大标题。手写感靠自然的笔画、字形节奏和轻微倾角来表现，不靠逐字乱转和不齐的基线。

文字容器有奶油色刷痕、白色描边、彩色短条、撕纸、便签；按所选分支取用，不全部叠加。粗标题负责第一眼，较轻的文字负责解释，标签建立图文对应。优先保证手机上读得清，不照搬参考图的信息量。

色彩跟着产品和题材走。下面是分支选项，不把所有项目都做成米色，也不套用某个品牌的配色：

- 母婴：奶油、棕、柔蓝或柔绿
- 户外：自然景色衬白字，少量黄线划重点
- 同类多款产品：用各自的包装色区分款式
- 植物与个护：米白、深绿、陶土色

## 六个风格分支

| 分支 | 字体与排版 | 适用任务 |
|---|---|---|
| 刷痕手账 | 奶油或浅彩刷痕，圆润笔字，短清单，少量 emoji | 日常护理、打包、随身携带 |
| 人物近景配醒目标题 | 顶部斜向色条，粗字白边，侧边细字加箭头 | 人物分享类主题；不做诊断或效果暗示 |
| 户外白字涂鸦 | 在自然留白处直接写白色干刷笔字，黄线划重点，白线小图 | 旅行、运动、户外生活方式 |
| 撞色撕纸拼贴 | 厚字或干刷字，撕纸层，产品白边剪影，局部素材 | 年轻活力、主题编辑；同一张里不混两种字体 |
| 产品对比笔记 | 产品对应自己的包装色，顶部标题、中部商品、下部清单或局部特写 | 单品讲解、有真实依据的对比、适合收藏的信息 |
| 自然植物剪贴簿 | 厚重无衬线标题配细笔注释，粗撕纸边、胶带、植物插画 | 居家、个护、气味与生活方式 |

每个项目选一个分支，最多再借一个分支的光线或场景，并写明各自负责什么；不把六个分支混在一起。

## 迁移与事实边界

只借风格手法，不复制参考图里的文案、数字、日期、包装、人物身份、症状、认证、功效、成分和使用方法。“自用”“回购”“亲测”这类说法要有真实资料。箭头和图标也可能暗示效果，审核时连同它们的视觉含义一起看。

参考里的前后对比、诊断类画面不当作可以生成的模板；参考里出现的原料、水果、植物，不因此成为新产品的配方依据。参考里的宣称一律不核验，也不收进卖点库。

## 默认摄影调性

简洁画面，自然柔和的漫反射，克制的低饱和度，细腻的明暗和真实的摄影细节；保留准确的品牌色和可信的肤色。强直射光、高饱和、密集贴纸是部分风格的特征，只在这次任务明确需要时才用。用户另有指定时，按用户的来。

## 验收

提示词写了不等于做到了：每张图都看实际输出再交付，尺寸以导出文件为准，放大或插值导出要如实说明。
