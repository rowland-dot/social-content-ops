# 人像摄影模块（十四条，可选）

适用：商业人像、人物与商品互动、产品场景的生图或修图提示。这是一份可选的模块清单，不是技能。用户当次的明确要求优先；已有的确认持续有效。

## 用法

- 根据当前任务选择适用的模块：一般人像采用皮肤、光影、姿态和服装的基线；站姿、行走、坐姿互为替代；手部模块只在手入镜时用；商品特写、室内、街拍、俯拍各用各自的镜头模块。不要把所有姿态、镜头和光圈堆进一张图。
- 用户的服装要求优先；没有要求时，服装按这篇帖子的场景定。修图不擅自改变原来的衣服、人物长相、姿势和构图。
- 不要把参数模板当作工具能力的保证。

## 十四个模块

1. 皮肤维度：保留真实皮肤毛孔与微小肌理，眼下细纹与嘴角纹理自然可见，无过度磨皮，无塑料感
2. 光影维度：左侧柔光箱主光，光比 1:2，鼻梁与颧骨有柔和高光，右侧自然渐变阴影，暗部通透无死黑
3. 姿态维度：身体重心轻微偏向一侧，肩膀自然下沉，头部微侧，下巴微收，嘴角带一丝极淡的笑意
4. 服装维度：面料柔软有垂坠感，纹理清晰，领口与袖口有自然褶皱
5. 镜头维度：85mm 中长焦人像镜头，f/2.8 浅景深，焦点锁定双眼，背景自然虚化
6. 影棚站姿：身体重心轻微偏向一侧，肩膀自然下沉，头部微侧，下巴微收，眼神平和看向镜头
7. 行走抓拍：身体自然前倾，一腿在前一腿在后，手臂自然摆动，头部微转看向镜头，服装随动作有自然褶皱
8. 坐姿：身体深靠椅背，头部微仰，肩膀放松，一手自然搭在扶手上，一手轻放于腿上，手指自然弯曲
9. 手部入镜：手部自然入镜拿取产品，手指弯曲自然，指甲干净，皮肤纹理真实
10. 人像特写：85mm 中长焦，f/2.8 浅景深，焦点锁定双眼，皮肤毛孔与细纹清晰可见，背景柔美虚化，无磨皮涂抹感
11. 产品细节图：100mm 微距，f/8 全景深合焦，产品表面纹理清晰锐利，边缘干净无毛边，无运动模糊
12. 室内场景图：50mm 标准镜头，f/5.6 中等光圈，前景产品绝对清晰，中景人物超清锁焦，背景自然浅景深虚化
13. 户外街拍：35mm 广角，f/4，焦点锁定人物面部，人物边缘清晰，背景街道自然虚化，无运动模糊
14. 桌面产品俯拍：50mm 标准镜头，f/5.6-f/8，高角度 45° 俯拍，产品整体清晰，桌面材质纹理可见，无阴影死黑

## 执行时怎样理解

1. **肤质。** 保留真实毛孔、微小肌理、自然的眼下与嘴角纹理。纹理服从年龄、景别与光线，不把年轻人处理得明显老化，不对全身铺同一层纹理。近景可见的细节在半身图里应更克制。要求绒毛时，只呈现少量自然的细绒毛。
2. **去伪纹理。** 排除波纹、迷宫线、蜂窝、龟裂、鳞片和均匀重复的毛孔。皮肤、针织、背景各有不同材质；不能用增加纹理代替真实摄影。清除伪纹理时保留真实的局部肌理，不靠全局磨皮或模糊掩盖，也不用粗颗粒实现胶片感。
3. **光线。** 柔光箱主光、自然渐变阴影；鼻梁颧骨的高光克制，暗部通透。“光比 1:2”的测量定义没有给出，不擅自解释成主灯和辅灯的功率比；执行以柔和低反差、亮暗有层次为准。
4. **姿态。** 选一种场景姿态，保持重心、关节和动作的逻辑。用户明确要求正面、严格对称或冷静表情时，不额外加入微侧头或笑意。拿商品必须有准确的接触、合理的尺度和自然的遮挡。
5. **镜头。** 用户给的焦距和光圈是优先的摄影语言。85mm、f/2.8 不保证双眼和前伸的商品同时清楚；需要多个焦点时，先让关键对象接近同一焦平面，再以必要的清晰区域为先。不能宣称 100mm 微距 f/8 一定全景深，也不能保证 50mm f/5.6 在任何空间里同时得到清晰的前中景和浅景深背景。必要时调整距离、焦平面或提出景深合成，并说明调整。
6. **俯拍。** 高角度 45° 俯拍不自动换成 90° 垂直平铺。
7. **商品。** 包装和颜色依据提供的素材；没有品牌要求就保持空白，不编造标签与宣称。修复时不擅自删掉必要的品牌信息。
8. **色彩与画面。** 默认清理无关装饰，柔和漫射光、克制饱和度、细腻的色彩和明暗过渡，保持准确的肤色和品牌色，不整体泛灰泛黄。

## 提示与成片

提示依次写明：任务、主体与商品事实、所选动作、构图、光线、材质和清晰区域，最后列出与任务有关的禁项。避免重复堆词。画幅和交付像素单独确认或沿用；描述里的“2K”不代表工具实际输出的分辨率。

每次先做一张，检查实际结果后再交付；不要把提示词的自检当作图片验收。验收重点：

- 真实细微的肤质仍在，没有塑料感、蜡感、过度磨皮和波纹伪纹理。
- 光线方向、渐变阴影、柔和高光和暗部细节协调。
- 姿态、手指数量、关节、指甲、商品接触与比例可信。
- 罗纹按服装结构延伸，褶皱服从受力，皮肤和布料不共用纹理。
- 双眼或任务指定的商品与互动区域清晰，虚化有空间逻辑。
- 画幅、裁切、留白、文字和包装符合当次要求。
- 检查最终文件像素；若通过放大达到更大尺寸，明确说明是放大导出，不声称原生分辨率或新增真实细节。

发现明确的缺陷时做有针对性的修正；这个做法只对用户已批准的图适用，没有批准的图按技能里的重出办法办。交付时简述变化和限制，不保证“完全去除 AI 感”。未经用户确认，不把单次结果升级成永久的审美规则。
