# 商业人像与修图工作流

适用：商业人像、人物与商品互动、局部修图。这是工作方法，不是技能；不代表每张成片都已获用户最终认可。

## 长期偏好

- 画面简洁，移除无助于任务的杂乱装饰；自然柔和的漫反射，整体饱和度克制，保留准确的肤色和产品色。
- 胶片质感体现在细腻的色彩和明暗过渡，不用粗颗粒、脏污纹理或模糊来模拟。
- 皮肤保留真实毛孔、微小肌理、自然的眼下细纹和嘴角纹理；需要时有少量绒毛。不要过度磨皮、塑料感、蜡像感。
- 波纹、迷宫线、蜂窝、龟裂和重复毛孔是需要排除的伪纹理。细节服从年龄、景别和材质，不把针织纹理迁移到皮肤上。
- 做一张，检查，再扩展；修好一张交付一张。已经确认的选择不反复问。

## 八步

1. **读取与确定范围。** 读适用的标准；明确这一轮是新图、局部修复、换装还是姿势迁移。整理已确认项，只有缺少关键决定才询问。
2. **查看输入并分清角色。** 人物图约束身份，服装或包装素材约束外观，姿势图约束身体关系，风格图约束光色。不要把姿势参考里的脸、眼色、服装、饰品一起迁移。不能用文件名代替实际看图。
3. **写简洁的执行说明。** 说明这次要改的部位和要保留的东西。姿态、机位、光线、材质、清晰区域用可观察的描述。站姿、坐姿、行走互斥；镜头参数按任务选择。
4. **生成一张。** 使用图像工具；参考路径要有效。
5. **检查实际输出。** 先看整体构图与裁切，再查面部、肩颈、手部、衣料、背景与产品的接触区。重点查波纹伪纹理、过度磨皮、高光、身份漂移。需要细看时做局部放大检查，不能只凭缩略图宣布通过。
6. **针对缺陷修正。** 每一轮只盯一个明确的缺陷；优先从较干净的源图修正，避免在带伪纹理的版本上连续叠加。较大的姿势迁移会重新生成身体和脸部细节，须核对身份是否近似，不承诺像素级保留。
7. **核验交付。** 实际读取像素尺寸，另存而不覆盖原图。分清原生生成分辨率和插值放大后的尺寸；放大不能创造真实细节。给最终文件，避免混淆多个中间版本。
8. **记录反馈。** 区分用户明确的要求、工具实际的表现和推断。新的审美偏好未经确认不写成全局强制规则。

## 经验

1. **增加纹理不等于真实。** 强调毛孔与摄影细节的提示，没有可靠地防止伪纹理；不能因为负面提示写了“无波纹”就宣称消除成功。
2. **清波纹与保留肤质要平衡。** 强力的表面平滑能清掉伪纹理，但也会让皮肤过于光滑。应区分局部的自然纹理和连续重复的图案，而不是全图平滑。恢复肌理的结果只是一次生成尝试，未经确认不记为稳定的解决办法。
3. **提示里的像素与百分比不是执行保证。** 要求某个尺寸可能仍得到较小的输出，只能插值放大；留白比例也可能偏离。每次都要实际检查。
4. **服装和姿势迁移要写清参考的职责。** 原图作身份和服装依据，姿势图只作姿势依据，避免复制参考模特的非目标特征。是否足够相似，由用户判断。
5. **报告要与可观察的证据一致。** 区分“已按此要求执行”和“可在输出里确认”；微小绒毛等没有放大验证的细节不作完成保证。不承诺完全去 AI 感。

## 一个项目自己的条件不是通用默认

某个系列用的模特、服装颜色、姿势、画幅、交付像素和留白，只属于那个系列，不套用到所有人像图。不把“用户继续下一步”当作明确满意的评价。
