# 资料包里要读包装上印的字的句子：逐条不执行（issue 93）

负责人的规则（CLAUDE.md“Product pack wording is never checked”，2026-10-23）：真实商品包装上印的字从不核对、不列清单、不放大比对、不拿去问用户，也不作为缩小、裁掉、藏起或重画包装的理由；检查包装是不是真包装（形状、比例、颜色、Logo 和标签的位置、大小）照旧。`SKILL.md`“动手前先读”里的那一段（issue 72）点名了五个例子并给出总则；资料包里还有下面这些同类的句子，在这里逐条点名。资料包里的这些文件原样不动，这里只是不执行它们的包装文字部分。

“不执行”的意思：这一句里的包装文字部分从不核对、不列、不比对、不放大、不报，也不是重画、缩小、裁掉或藏起包装的理由。“其余照旧”的意思：这一句里其余的要求仍然有效，也就是真实包装的形状、比例、颜色、Logo 和标签的位置，以及包装的大小；大小只按形状用眼睛判断，不读印的容量。

每条先写资料包里的文件和行号，再写原句里的一段（原文，找得到），再写哪部分不执行。
