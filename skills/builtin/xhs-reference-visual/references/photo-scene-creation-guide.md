# 账号的创作指南（issue 125）

每个账号的画像里有一份 `creation-guide.md`：这个账号的图怎么拍、帖子怎么写的限制和指引（图一部分、帖子一部分，每条规则写明它管哪一类卡或帖子）。这个技能只留对每个账号都成立的规则；只对某个账号成立的规则写在那个账号的指南里。



## 第一步：整份读完

1. 运行 `python3 skills/shared/scripts/creation_guide.py check --brand <品牌>`。它在账号画像所在的地方找：`profiles/<品牌>/creation-guide.md`；画像放在仓库外面的账号（`EASEL_PROFILE_DIRS` 映射的文件夹）就在那个文件夹里。找到时它打印路径和最后修改的日期。
2. 把这份指南从头读到尾，再做别的。读完之前不研究、不写计划、不画。
3. 套系计划在第一个 `##` 段落之前写一行：`创作指南：<路径>（最后修改 <日期>）`。这一行不是新增的固定段落，计划页照原样显示它。

## 没有创作指南

命令说“没有创作指南”（退出码 2）时：停下，告诉负责人这个账号没有创作指南，提议从 `profiles/_template/creation-guide.md` 建一份；负责人同意之前不研究、不写计划、不画，也不写任何帖子的文字。

## 留在技能里的通用规则

只有对每个账号都成立的规则留在技能里：
- 光只有一个来源，看起来可信；
- 对焦在重要的物、人或景上；
- 重要的东西不被画面边缘切掉（见 [photo-scene-safe-margin.md](photo-scene-safe-margin.md)）；
- 照片画的就是这张卡的字说的；
- 整套保持和封面同一个地方和光；
- 以及审批步骤、检查和文件放法。

某条规则只对一类卡、一类商品或一种场景成立时，不写进技能，写进账号的指南并写明范围。
