# 手绘字的说明（issue 113）

套系计划里 Codex 画的字，按它在图上看得见的样子来写说明，细则都在这里；SKILL.md 只留门、出图规则和检查，各自指回这里。来源：Lovart 技能包评审第 T17 行（“至少写出五项能在最终图上看见的形态特征”“设定变形幅度：明确字形压扁程度、笔画松紧度、撇捺夸张幅度、基线波浪起伏强度”“Use the first **only** to calibrate the date's visual size and the second **only** to calibrate the headline's thin loose handwriting”）。

## 适用范围

- 每一个 Codex 画的字体样式：手绘整套的字，和打字整套里仍由 Codex 画的手写部分（例如打字标题旁的细笔批注）。
- 涂鸦、笔刷底和其他承托不是字，不需要这份说明。打字字体（issue 81）由代码设字，不受影响，也不变。

## 计划里每个手绘字体样式写四部分

在套系计划的字体体系一行里写：

1. 设计记忆里的哪一类（`<资料包目录>/file/DESIGN-MEMORY.md` 里的三类之一），加上承托形式，和现在一样。
2. 至少五项在画好的图上看得见的形态特征，写成能指给人看的描述，例如：字面宽窄和高宽比例、字腔开合、笔画粗细和粗细变化、笔画端头和质感（圆头，或干刷带飞白）、倾角、字距和节奏、和涂鸦的重叠。“可爱”“灵动”“高级”“lively”这类看不见形状的赞美词不算一项； 的答案是写出灵动在图上长什么样，不是写“灵动”。
3. 三个档位，每个写档位（无 / 轻 / 中 / 强）和一句话说这个档位在图上长什么样：字形压扁程度、笔画松紧度、基线波浪起伏强度。基线波浪起伏强度最多是轻，因为团队设计记忆写的是“轻微倾角”，并且“不靠逐字乱转和不齐基线”。
4. 这个样式只有一张参考图（写文件名），再写一句它可以借什么，格式固定：图 N 只用来定<哪一块字>的<哪几项特征>，不借它的字、版面、颜色、商品和人物。

## 参考图是哪一张

- 负责人批准封面之前：一张这一类的图，取自团队的参考帖，或这篇帖子自己的主题研究存下的图集。
- 负责人批准封面之后：已批准的封面就是后面每一张卡的手绘字的那一张参考图（SKILL.md 本来就允许把已通过的封面当字体和风格参考传入）。
- 一张图可以同时是两个字体样式的参考，只要它同时画了这两种字，例如已批准的封面上的标题和批注。
- 参考图占用两个风格参考位中的一个，数量和角色由图片脚本决定，图片脚本不改。主参考同时是字的参考时，提示词分开写：它给场景什么，它给字什么。

## 门

计划里任何一个 Codex 画的字体样式缺任何一部分，计划没有写完：不交给用户，不画任何一张卡，和计划拒绝系统默认字体一样。打字字体的整套不受影响。

## 提示词

每一张有 Codex 手绘字的卡，提示词带上这个样式的特征、档位和借用句，照计划原样抄，不改写。写完提示词对照版面计划的检查，也查这三样在不在。

## 检查

套系并排检查里，用眼睛把每张卡画出来的手绘字对着计划里的特征、档位和那张参考图看。漏了计划写的特征，或超过计划写的档位（例如基线波浪成了不齐的基线），这张卡不合格，属于三级。负责人没有批准的卡照干净重出，已批准的卡照已批准卡的修改，或如实报告给用户。

这一页不读、不列、不报包装上印的字（见 SKILL.md 里负责人的规则）。
