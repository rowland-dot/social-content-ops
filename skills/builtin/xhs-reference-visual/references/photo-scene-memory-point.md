# 封面的记忆点（issue 98）

来源：2026-10-28 Lovart 复盘的缺口表 T1 行（`outputs/_reviews/2026-10-28-lovart-redo/synth/GAPS.md`）。Lovart 的原话：“如果只看 5 秒，会记住什么？”。这是 Lovart 的规则，还没有在 Easel 里试过；Lovart 的文件没有拿进来。

- 封面方向表（[photo-scene-plan-page.md](photo-scene-plan-page.md)）每个方向有一行“记忆点”：读者在信息流里看这张封面五秒之后心里还留着什么，写成看到的东西加上它对读者意味着什么，不是口号，不是大类。
- 和“读者的问题”不同：读者的问题是读者翻到某一张卡时在问什么，那张卡回答它；记忆点是看完封面之后留下什么。
- 记忆点和方向表一起写，在建计划页之前，在画任何一张封面之前。每个方向一行，空了命令停下。
- 用户选定方向之后，选定记录（[photo-scene-cover-versions.md](photo-scene-cover-versions.md)“用户选定之后”）原样带上该方向的记忆点，作为这套封面的记忆点；后面的卡没有记忆点。
- 记忆点不依据真包装上印的字，也不读、不列、不报那些字。
