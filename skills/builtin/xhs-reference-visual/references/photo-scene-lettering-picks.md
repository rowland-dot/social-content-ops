# 字体和样式 A/B/C/D（issue 89，issue 121）

照片场景帖的字，不由套系计划自己定，由负责人在他选定的封面上分两步选：先选字体，再选样式，各是四选一，A 到 D：A 是原版（封面本来就带的字），B、C、D 是三个新的。不并成一张九选一的菜单。细则都在这里；SKILL.md 只留步骤和负责人的规则，指回这里。

负责人的规则（CLAUDE.md“Photo-scene post images follow one approval process”第 4 步）



负责人，2026-10-28（issue 121，第 1 篇按年龄段，选样式时）

**原版**：选项 A 永远是原版，标“原版”。它不画、不设，就是用户已经看过的那一份，所以免费，不重画，也不算在手绘的张数里（下面问 yes 时要写的张数只数 B、C、D 里手绘的）。

## 什么时候

选定封面之后、其他任何一张卡画之前（封面怎么选见 [photo-scene-cover-versions.md](photo-scene-cover-versions.md)）。选项都放在负责人选定的那一张封面上，四个封面都带计划里的字，所以一定有原版：打字字体的整套，底图的标题区留空，字由代码设上（issue 81）；手绘的封面自带它的字。字体和样式的选项放在这张封面上，只有字不同。

## 第一步：字体 A/B/C/D

- 选项 A 是选定封面自带的字，原版，就是封面对比里给用户看的样子，不重画。B、C、D 是三种新字体，字形不同，也不同于原版的字形：衬线、无衬线、楷体毛笔、手绘各算一种字形。同一种字体的两种粗细或一种字体换颜色不算，那是同一种字形。厚重无衬线的手绘大标题和已装的 Noto Sans CJK SC 是同一类字形，不要同时当两个选项。
- 选项从两处来，设计记忆里的字只是选项的来源，不是计划自己做的决定：
  - 已装的打字字体（见 SKILL.md“打字字体的整套”里的字体一行）：Noto Serif CJK SC（衬线）、Noto Sans CJK SC（无衬线）、LXGW WenKai（楷体）。
  - 团队设计记忆里的三类字：`<资料包目录>/file/DESIGN-MEMORY.md` 第 17 行：圆润粗笔/细笔手写；有干刷和飞白感的白色笔字；厚重无衬线大标题。这三类是手绘。
- 每个选项写明它是哪一种：打字（哪一个已装字体）或手绘（设计记忆里的哪一类）。三个新选项通常是打字和手绘混着：已装字体里字形不同的，加上设计记忆里的手绘字。
- 并排给用户看：四个选项都放在同一张选定的封面上，标 A、B、C、D（A 标原版），只有字不同，别的一概不变。把图的位置交给用户，然后停下。

## 第二步：样式 A/B/C/D

- 选项 A 是上一步选定的字，原版，就是用户在第一步看到的样子，不重画；第一步选的若是原版，它就是封面本来的样式。B、C、D 是在用户选定的那个字体上做的三个新样式。每个样式写明四样：颜色、描边、填充、装饰（例如“暖橙 #F28C28 的字，白色 6 像素描边，纯色填充，标题旁一朵小桂花”），三个样式在这四样上明显不同。
- 颜色按颜色表办：每个样式的颜色不得是颜色和层级对应表里别的行的颜色；负责人选中的样式的颜色成为表里“字”这一行的颜色（SKILL.md“颜色和层级的对应表”一节已写明）。
- 纯粗黑笔画永不作为样式出现。 纯粗黑笔画的意思：黑色或接近黑色的字，没有颜色、没有另一种颜色的描边、没有装饰。计划对它和拒绝系统默认字体一样：这样的样式不进选项，也不进提示词。
- 并排给用户看，同样放在同一张选定的封面上，标 A、B、C、D（A 标原版），只有字的样式不同。

## 选项怎么出

- 打字的字体和打字字体上的样式：用 `skills/builtin/xhs-note-creator/scripts/text_on_image.py`（issue 81）在标题区留空的封面上设字，一个选项一份样式文件。不画图，免费，所以不用问用户。
- 手绘的字体和手绘字体上的样式：是 Codex 在选定封面上的重画，只改字（和字边的装饰），别的不动，按已批准的卡办（SKILL.md“已批准卡的修改”，issue 91，选定的封面就是已批准的卡）：用 `--base-image` 传入选定封面。这条路耗负责人的 ChatGPT 额度，所以先等用户的 yes：用问题工具问，写明要画几张（手绘选项各一张），用户答了 yes 才画。
- 两步都选原版：封面的字原样不动，不画不设；打字的整套，封面的样式文件就成为这套的 `typed-styling.json`（见下面“选定之后”）。
- 混着选（“A 的字体，B 的描边”）：新做成一个选项，再给用户看一次，看过才算选定。
- 用户的选择只能来自用户自己的回复；沉默、没有反对、猜他会选哪个都不算，也不替他选。

## 选定之后

- 选定的字体和样式写进套系计划的字体体系一行（`set-plan.md`），取代计划自己定的一种字体体系；设计记忆里的三类字只是选项的来源。选定的是哪个、哪一天，记入批准记录 `approvals.json`（`kind` 是 `lettering-pick`，见 [photo-scene-approvals.md](photo-scene-approvals.md)），不写在这一行。
- 打字的选定：选定的样式存成这套的 `typed-styling.json`（字段照 issue 81：`font_file`、`fill`、`outline_width`、`outline_color`、`shadow`、`sizes`），每一张卡，封面也算，都按它设字，issue 81 的 `--check-records` 照旧通过，不改。
- 手绘的选定：选定封面上的字就是后面每一张卡的字体和风格参考（传设字之前的底图的做法见 SKILL.md“出图”）；SKILL.md 里已有的套系并排检查看到某张卡的标题字和选定封面上的标题字不一样，这张卡不合格。
- 选定之后，其余的卡才开始画，选定的字体和样式只给标题（封面的主标题和副标题、每张卡的页标题）：从封面起每张卡的标题都一样，只有字号不同；正文用整套一个朴素的正文样式，见 [photo-scene-body-text.md](photo-scene-body-text.md)。

## 再装一个字体（issue 119）

负责人，2026-10-28： 订下这件事时他又说

**什么时候装**：字体 A/B/C 需要一个已装字体（Noto Serif CJK SC、Noto Sans CJK SC、LXGW WenKai）都没有的字形时。装不装由计划自己判断，不问负责人。一个字体作为 A/B/C 的一个选项给负责人看，就算用上了：选项是已经设好字的小样，字体得先在这台 PC 上。负责人没选它，它留在那里，不删（删一步只多一件事，没有更安全）。不批量装，不留字体库，没有被哪个帖子的选项用上的字体不装。

**去哪找，按顺序**
1. Google Fonts 的仓库 `google/fonts`，`ofl/<名字>/` 文件夹：每个中文字体一个文件夹，一个字体文件，旁边是它的 `OFL.txt`。下载地址固定到一个提交，不用分支：`https://raw.githubusercontent.com/google/fonts/<40 位提交>/ofl/<名字>/<文件名>.ttf`，从不用 main。分诊时（2026-10-28）通过 GitHub 的文件列表核对过这样放的有 `ofl/mashanzheng`、`ofl/longcang`、`ofl/zcoolkuaile`、`ofl/zhimangxing`、`ofl/liujianmaocao`、`ofl/zcoolxiaowei`、`ofl/zcoolqingkehuangyou`；`ofl/zcoolkuaile` 当天的最新提交是 `6d49995f5d8f1c7d476760a580ffb89ce1e52c5d`，用时再查一次提交。
2. `jaywcjlove/free-font` 和 `kevchentw/awesome-chinese-fonts` 两份清单只是找候选的地方，每个字体自己的许可证为准。从清单找到的字体，要从字体自己项目的版本发布，或固定到提交的地址下载，不从清单下载。

**许可证怎么查**：字体自己的许可证文件，和字体从同一处下载，必须是 SIL Open Font License 1.1 或 Apache License 2.0。这两种都允许商用，包括把字画进图里。命令不认别的许可证：项目自己写的“免费商用”说明、没有许可证文件，一律拒绝，什么也不装，打印原因。这样的字体问负责人，不自己决定。

**命令**（一次只装一个字体文件）：

```
python3 skills/builtin/xhs-reference-visual/scripts/install_font.py --font-url <字体文件的固定地址> --license-url <同一处的许可证文件地址> --post <这是给哪篇帖子装的>
```

- 拒绝：没有固定到提交或版本号的地址；不是单个 .ttf、.otf 或 .ttc 的文件；许可证不合格。
- 装到 `/usr/local/share/fonts/on-demand/<字体>/`，旁边放许可证文件和 `source.json`（下载地址、sha256、许可证名称和地址、日期、帖子），只对这个文件夹刷新字体缓存，不碰其他字体。
- 同一个地址再跑一次，说 already done，什么也不下载；同名的另一个文件已经在了，拒绝并原样不动。
- 屏幕上会打出 `fc-list` 报的字体家族名，和要写进 `typed-styling.json` 的 `font_file` 文件名。设字脚本 `text_on_image.py` 按文件名在这个目录的各个子文件夹里找，找不到仍然报“not found”，不悄悄换字体。

**记录**：负责人选定的字体如果是这样装的，套系计划的字体体系一行（见上面“选定之后”）除了字体名，还写它的来源和许可证：下载地址和许可证名称，取自 `source.json`。
